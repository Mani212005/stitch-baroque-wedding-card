# Royal Baroque Wedding Invitation - Shikha & Pavitra

An opulent, high-Victorian & late-Baroque digital wedding invitation card web experience inspired by royal stationery, copperplate engravings, and bespoke letterpress craftsmanship.

## Features

- **Antique Baroque Aesthetic:** Gilded foil gradients, parchment noise textures, acanthus flourishes, and double hairline gold rules.
- **Imperial Typography:** Cinzel, Playfair Display, Great Vibes, and Pinyon Script.
- **Interactive RSVP Modal:** Guest confirmation with attendance selection, attendee counter, warm wishes notes, and celebration animations.
- **Add to Calendar (.ics):** Generates and downloads standard iCalendar files with event schedule (Sacred Vows at 4:00 PM, Imperial Reception at 7:30 PM).
- **Palace Venue Guide:** Instant venue directions and Google Maps navigation.
- **Royal Shehnai & Symphony Audio:** Web Audio API synthesized classical raga tanpura and shehnai harmony.
- **Ambient Petal Shower:** Canvas-based falling rose petals and shimmering gold particles with toggle control.
- **Mobile & Desktop Responsive:** Pixel-perfect display across all viewport sizes.

## Local Development

Open `index.html` directly in your browser or run:

```bash
npx serve .
```

## Deployment

Deploy directly to Vercel:

```bash
vercel --prod
```
